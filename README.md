# 飯友 Meal Buddy · 互動作品展示

先選想吃的餐廳，再找願意一起吃飯的朋友。18+ 純交友共餐概念，支援一對一邀請與 2–6 人飯局。

**[開啟線上 Demo](https://mina201199.github.io/meal-buddy-demo/)** — 手機、電腦皆可操作，無須登入或安裝。

## 三分鐘試玩

1. 點選語音示範，或輸入「明天午餐想吃鹹的，預算100」。
2. 調整條件、依距離或評分排序，選擇餐廳。
3. 切換「現在／等等／明天」，查看飯友資料並發送邀請。
4. 在飯局頁模擬接受邀請、體驗聊天室，也可建立或申請多人飯局。
5. 到「我的」重設 Demo，重新開始。

## 技術與設計

- 原生 HTML、CSS、JavaScript，無需建置或安裝套件。
- 手機優先響應式介面，桌面置中展示手機畫面。
- data.js：虛構資料與原創 SVG 插畫。
- logic.js：本地需求解析、排序、用餐時段、邀請與名額規則。
- app.js：畫面互動、邀請狀態與 sessionStorage 保存。
- GitHub Pages 靜態部署。

## 展示範圍與限制

這是互動原型，不是真實交友服務。人物、餐廳、距離、評分、驗證及訊息均為虛構；插畫不是本人照片。AI／語音是本地模擬，未呼叫 OpenAI，不會錄音、定位或真的聯絡他人。

互動資料保存在目前瀏覽器分頁的 sessionStorage，不會跨裝置同步。Demo 以台北日期中午作為情境時間。請勿輸入真實個資、密碼或金鑰。

後續正式服務需另行實作後端、帳號權限、即時通訊、通知、安全檢舉及 AI 整合。所有 API 金鑰應只由後端保管。
